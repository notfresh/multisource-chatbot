# 📄 产品说明书：**MindLog — 可编辑、可加权、可掌控的 AI 对话日志系统**

> **一句话定位**：  
> 不是聊天记录，而是你亲手筛选、标记、塑造的认知轨迹。

---

## 一、产品愿景

打造一个**以用户为中心的对话操作系统**，让用户在与大模型的每一次交互中，都能：
- **主动选择**保留什么、删除什么；
- **明确标记**哪些观点特别重要；
- **长期掌控**自己的思维资产，而非被平台算法或默认设置绑架。

> ✨ 你的对话历史，只属于你，且由你定义价值。

---

## 二、核心原则

| 原则 | 说明 |
|------|------|
| **用户主权** | 所有对话内容的留存、删除、编辑权完全归用户所有。 |
| **无状态模型 + 有状态用户** | 大模型本身无记忆，但你的“认知日志”是有结构、可演化的。 |
| **轻量干预，高价值沉淀** | 每次只需简单操作（保留/删除/加权），即可积累高质量个人知识。 |
| **离线优先，隐私第一** | 支持本地存储，敏感内容不出设备。 |

---

## 三、核心功能

### 1. **对话后即时决策**
- 每轮 AI 回答结束后，弹出轻量操作栏：
  - ✅ **保留**：存入个人日志库；
  - ❌ **删除**：彻底丢弃，不留痕迹；
  - ⭐ **设为重点**：标记高权重，影响后续检索与遗忘策略；
  - ✏️ **编辑后保存**：修改措辞、提炼要点后再存。

### 2. **观点权重系统**
- 用户可为任意保留的对话条目设置权重（1–5 星）；
- **权重 5 = 核心工作区**：最重要的内容，用于后续生成高质量文章总结
- 高权重条目（权重 >= 4）：
  - 在知识检索中优先召回；
  - 衰减更慢（“遗忘曲线”平缓）；
  - **自动进入核心工作区，可聚合生成文章/总结**；
  - 可自动聚合为“个人方法论卡片”。

### 2.1 **核心工作区（5星专属功能）**
- **可创建多个工作区**：用户可以创建多个主题工作区，如"AI学习"、"项目规划"、"读书笔记"等
- **会话关联工作区**：创建新会话时，可以选择关联的工作区（可选）
- **自动创建工作区**：如果会话没有关联工作区，当标记第一条5星内容时，系统自动创建并关联工作区
- **5星内容自动进入**：标记为 5 星的内容自动进入当前会话关联的工作区
- **跨会话聚合**：同一工作区下的所有会话的 5 星内容都聚合在一起
- **内容聚合**：基于工作区的内容，生成：
  - 📄 **高质量文章总结**：将相关对话整理成结构化文章
  - 📋 **知识卡片**：提取关键观点和方法论
  - 📊 **主题分析**：按主题分类整理核心内容
  - 🔗 **关联图谱**：展示核心观点之间的关联
- **持续更新**：随着新内容加入，工作区自动更新，文章可重新生成

### 3. **智能上下文管理（后端实现）**
- 采用 **滑动窗口 + 语义摘要** 控制输入长度：
  - 最近 N 轮对话直传模型；
  - 更早内容经摘要后作为背景提示；
  - 高权重条目可“常驻上下文”。
- 确保长对话不卡顿、响应速度快。

### 4. **日志可视化与管理**
- 时间线视图：按话题/日期浏览对话；
- 标签系统：自动打标（如 #决策 #灵感 #待验证）；
- 搜索 & 过滤：按关键词、权重、标签快速定位；
- 导出支持：Markdown / JSON / Obsidian 兼容格式。

## 四、技术架构（简版）

```
[安卓客户端] 
    │
    └─ HTTP/WebSocket → [Python 后端（FastAPI + LangChain）]
                              │
                              ├─ 对话流式生成（streaming）
                              ├─ RAG：挂载用户知识库
                              ├─ 状态管理：对话历史 + 权重 + 删除标记
                              └─ 存储：SQLite / JSON / Chroma（可选）
```

> 安卓端专注 UI 与交互；所有智能逻辑由 Python 后端处理。

## 六、差异化优势

| 对比项 | ChatGPT / Claude 官方 | MindLog |
|--------|---------------------|--------|
| 历史记录 | 全量保存，不可精细控制 | **用户主动筛选，只留精华** |
| 重点标记 | ❌ **无此功能** | ✅ **支持权重（1-5星）+ 遗忘控制** |
| 上下文管理 | 黑盒，简单时间截断 | **透明可控，高权重优先保留** |
| 消息删除 | 删除整个会话 | **精确删除单条消息，不影响上下文** |
| 数据归属 | 平台持有 | **完全本地/私有** |
| 认知沉淀 | 被动堆积 | **主动建构，形成个人知识库** |
| 长期价值 | 对话记录 | **认知轨迹，第二大脑** |

> 💡 **关键洞察**：官方产品追求简单易用，我们追求精细控制。权重功能是官方产品**没有的核心差异化功能**，让用户从"被动记录"变成"主动建构"。

## 八、核心工作区功能详解

### 8.1 核心工作区的价值

**问题场景：**
- 在长期对话中，积累了大量有价值的问答
- 想要将这些精华内容整理成文章、总结或知识卡片
- 手动整理耗时且容易遗漏

**解决方案：核心工作区（5星）**
- 用户只需标记重要内容为 5 星
- 系统自动收集所有 5 星内容
- 一键生成高质量文章总结

### 8.2 使用流程

**方式一：提前创建工作区**
```
1. 创建核心工作区（如"AI学习"）
   ↓
2. 开启新会话，选择"AI学习"工作区
   ↓
3. 在对话中遇到重要内容，标记为 5 星
   ↓
4. 5星内容自动进入"AI学习"工作区
   ↓
5. 在"AI学习"工作区中，点击"生成文章总结"
   ↓
6. 生成关于AI学习的主题文章
```

**方式二：自动创建工作区（更流畅）**
```
1. 开启新会话（不选择工作区）
   ↓
2. 在对话中遇到重要内容，标记为 5 星
   ↓
3. 系统自动创建工作区（名称基于会话标题或消息内容）
   ↓
4. 5星内容自动进入新创建的工作区
   ↓
5. 后续的5星内容继续进入该工作区
   ↓
6. 在工作区中，点击"生成文章总结"
   ↓
7. 生成主题文章
```

### 8.3 生成内容类型

1. **文章总结**
   - 按主题组织核心观点
   - 包含完整的问答对
   - 添加逻辑连接和过渡

2. **知识卡片**
   - 提取关键概念
   - 结构化展示（问题-答案-要点）

3. **主题分析**
   - 自动识别核心工作区中的主题
   - 按主题分类整理

4. **关联图谱**
   - 展示核心观点之间的关系
   - 可视化知识结构
